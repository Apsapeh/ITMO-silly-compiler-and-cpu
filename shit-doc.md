# SHIT - Simple Head In Top

### Factorial
```
PROCEDURE FACTORIAL N:WORD RETURN WORD
  IF N EQUAL 1 OR N EQUAL 0
    RETURN 1
  ELSE
    RETURN N MUL FACTORIAL(N MINUS 1)

FUNCTION GREATER NAME:STRING
  WRITE "Hello, " NAME "!\n"
  WRITE "Please, write some number: "

FUNCTION MAIN
  CALL GREATER "SHIT"

  VARIABLE N:WORD 2
  READ USER_N
  SET N IS N PLUS USER_N
  
  VARIABLE RESULT:WORD FACTORIAL(N)
  WRITE RESULT
```
